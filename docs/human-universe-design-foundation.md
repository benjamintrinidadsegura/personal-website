# Human Universe — design foundation

One isolated composition, based on Convergence `426690464632caedc35b53477d749dd5043565f1`.

## Direction

The room is continuous deep navy. Local blue light defines a central search lens,
without the previous paper-coloured half-panel. Glass is reserved for the search
and its controls. Natural source imagery stays unfiltered. Editorial serif type
adds hierarchy; project context remains plain text from the existing record,
without a fabricated logo. The World Map has its own circular silhouette.

Desktop composes the selected subject on the left, a portrait above the right
side and project context below it. Supporting destinations anchor the lower edge.
Mobile uses one central lead image and two compact supporting entries. The search
lens stays at the geometric midpoint of the scene, including Focus and empty states.

## Deliberate boundaries

Only the Lab stylesheet and the Atlas presentation slots change. Catalog, query
engine, ranking, destinations, locale dictionaries, motion timing/choreography,
Focus component, route protection, homepage, tools, Writing and sitemap are retained.
All existing results remain accessible through the search and complete result list;
the neutral room retains six representative public records. Writing retains its
public index destination; demo concepts remain explicitly marked without links.

No new animations, scripts, assets, dependencies, service calls, or storage.
No Production changes, remote push, or deployment.

## Review

Actual browser captures and observations belong in the untracked engineering
artifact directory, not in public assets. Technical checks do not constitute
founder approval. Real-device Safari, physical touch, GPU performance and subjective
art direction approval require a later founder/device review.

## Evidence-led refinement

The first 1440px browser capture exposed project-caption overlap with the lower
right destination. Move that presentation slot from y=610 to y=555, leaving the
lower rail separate. Remove the duplicated visible World Map category label
(the button accessible name remains unchanged). Retain the 390px hierarchy:
lead imagery, title, centred lens, two supporting destinations. No motion changes.

The contrast review also brightens the input placeholder, giving over 4.5:1
even against the conservative opaque lightest glass stop. Native keyboard
focus remains cyan on controls and an inline title underline on content.

## Ice-blue material refinement

The existing endpoint/motion system is unchanged. Visible neutral connections use
0.32 stroke opacity at 0.8px, actual query matches and evidenced Focus relations
0.52 at 1px, and the active selection 0.8 at 1.25px. A restrained 2px shadow belongs
only to the active line. Retired/inert objects still fade with the existing motion;
Focus hides background connectors and retains evidenced satellites only.

Search, category and content keyboard focus can trigger one 180ms active-line
response. It has no infinite iterations, particles or dashed moving lights. The
animation exists only under prefers-reduced-motion:no-preference; the same static
hierarchy and focus emphasis remain under reduced motion. Native focus ownership
and the existing focus restoration are unchanged.

The lens retains its exact size, position, 6px blur and text colours. Fine inset
edges and one short contact shadow refine its depth; focus adds a local blue lift.
No metadata, typography, catalogue records, ranking or destinations are changed.

## Deep Navy lock and fluid settling

The original initial screenshot and recording source have identical RGB means at
four unobstructed 20x20px patches. Decoding the existing MP4 shifts those means by
only 1–2 RGB levels. That is evidence of small encoding differences, not evidence
that a player-specific washed-out appearance comes from a different brand colour.
No environment colour values are replaced; the existing palette remains the source.

A separate real CSS issue exists on mobile: Focus copy grew the 710px environment
to 855.625px, stretching percentage-based light layers. The light overlay now shares
`--room-height` with the interactive scene. The article's radial light has a stable
minimum 1100px paint canvas (approximately the approved initial reference height),
growing with tall viewports, independently of Focus copy. Content remains free to
grow; no clipping is introduced. Search coordinates and object composition remain.

Atlas uses the already planned path distance to choose a 180–320ms deadline rather
than assigning every change 340ms. Input is still synchronous and interruptible;
objects, lens and connection anchors sample one common eased progress. Existing
monotonic easing, endpoint geometry, object identities, collision planning and
listener cleanup remain. Reduced motion settles immediately. The CSS response is
shortened from 420ms to 180ms; it does not gate any interaction. Focus edge lighting
uses the same blur and palette, with no scaling or layout change.

Local QA measurement/proxy scripts live only in engineering evidence. They are
not application routes or release files. The controlled reduced-motion fixture
sets both the JS preference and disables no-preference CSS solely in that proxy;
it is explicitly distinct from a physical device or OS-level media preference.
## Reference-driven spatial experience

The founder's original 199.765-second video, annotated Osmo document, supplied
screenshot and README define the direction. Prior Lab recordings are comparison
evidence only. Osmo informs direct control; Cosmos informs a protected central
search; Lusion informs coherent environmental light; Apple informs selective
functional glass; Instrument/Pentagram inform genuine content identity and context.
These are transferable qualities, not copied artwork or third-party source code.

Atlas now has deterministic sparse/dense compositions. A stable object canvas
keeps the original image and DOM identity through changing roles. Scores only
weight presentation; the index, catalog, categories, membership and order remain
unchanged. The main title and search have separate clearances at 1280px. Mobile
has one lead and two nearby supporting objects rather than a scaled desktop room.

A horizontal gesture continuously samples a bounded route to the neighboring
valid selection. Routes are planned once per direction and reused while reversing.
The pointer displacement is the progress; there is no velocity/inertia integration.
Release uses final displacement and clamps to the existing result range. A vertical
intent is relinquished before capture. Controls, search, multi-pointer interruption,
cancellation and explicit keyboard alternatives retain their own behavior.

The lens retains 6px blur. A limited transmission layer and directional edge light
respond locally; text remains on a separate stable layer. No global distortion,
ambient animation, scroll reveal, new asset, dependency, service or tracking.

Focus reuses the same object and actual previous coordinates, increases visual
scale, and shows one relationship explanation only from shared catalog topics.
Return restores the pre-Focus perspective and the viewport saved before reading;
keyboard focus returns to a visible original object. Compact Focus keeps related destinations reachable below its
flowing details. Its environment and centered lens stay independent of detail height.

Verification artifacts, local-only instrumentation, recordings and baseline
comparisons live outside the checkout in the ignored engineering evidence folder.
Synthetic pointer fixtures explicitly do not claim native touch-device testing.
Frame measurements are bounded local samples, not a guaranteed frame rate.
Founder judgement and physical Safari/touch remain separate acceptance questions.
