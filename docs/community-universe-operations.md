## Reach publication and ingestion

The Vercel API documents authenticated count and dimension-aggregate queries. It has a country aggregate endpoint, and the count endpoint can group by day. Project/plan entitlement, full route filtering, exact coverage and complete account-specific API behavior still require verification. Hobby documentation states one month of reporting and 50,000 monthly events. The reporting window neither guarantees lifetime data availability nor proves physical deletion. See [API documentation](https://vercel.com/docs/analytics/web-analytics-api) and [pricing and limits](https://vercel.com/docs/analytics/limits-and-pricing).

The automatic ingestion boundary accepts two server-acquired, owner-approved aggregate periods. It accepts both only when they use the same closed end date and the recent range fits 30 days. It writes one atomic snapshot through an injected publisher. A future adapter must bind the scoped token, immutable project identity, verified public route allowlist and explicit period. Use scheduled polling once approved. A proposed execution frequency is once a day after the UTC day closes, subject to quota and protection of low-volume cells. Use idempotent replacement keyed by closed period, an authenticated private destination, and preserve the currently verified snapshot on provider or validation failure. Render only while within the existing freshness window. No adapter, schedule, credentials, collector mount or storage backend was activated.

An approved provider adapter should discard individual events, provider identifiers, referrer fields, attribution, raw locations and visitor estimates. Preserve the accepted page-view-only contract. Reverify payload and headers, routing, entitlement and retention before enabling collection. Persisting approved daily aggregate observations within the reporting window is a prerequisite for a longer since-start history. That requires an explicit retention decision. Do not fetch or backfill pre-measurement dates. For adjacent or overlapping periods, assess what difference calculations would expose before publishing both. Protect small counts, completeness metadata and overlapping release cohorts.

The visible total sums publishable country rows. The number of countries and continents uses those same rows. Unknown geographic records and territories without a drawable shape never receive a fabricated location. The map uses the existing ISC world-atlas package with Natural Earth boundaries at 1:50m. Country ISO alpha-2 to numeric crosswalk and regions use [UN M49](https://unstats.un.org/unsd/methodology/m49/overview/). Caribbean/Central America are grouped with North America for this display. Unmapped and disputed geometries stay neutral. A covered territory with no shape still appears in the ranking. The palette uses fixed bands at 5, 25, 100, 500 and 2,000 approved page views. The neutral color denotes absence of a published measure, for reasons including absent measurement, unknown coverage, or the privacy threshold.

## EchoWall and reactions

Apply the additive pending migration only after separate authorization and recovery approval. It adds one private Founder reply per Echo, private reactions and a bounded rate ledger. The service role can execute the public projection and reaction RPC but has no direct rights to those new tables. The Founder RPC uses the existing signed-in active admin and AAL2 check. Audit events record the actor and action without reply bodies. Hiding or rejecting suppresses both Echo and reply immediately. A physical parent deletion cascades to its dependent reply and reactions. Existing soft-delete/recovery controls are preserved. Closing the historic fixture cleanup is independent.

A reaction is one reversible vote per Echo and per first-party browser session. The scoped, random HttpOnly SameSite=Strict cookie is issued only on an explicit successful reaction and has no Max-Age or Domain. It is not consumed for analytics and is not included in URLs. Cookie paths cover all seven localized variants. The database uses a separate HMAC derivative per Echo, with an atomic unique index. Rate limiting uses an independent rotating digest of a trusted network header on Vercel or a fixed loopback test identity. Losing a session cookie means an earlier anonymous vote cannot be reversed from a new session. Shared browsers share a session, and resetting identity does not establish one vote per human. Enable only after the owner has decided cookie disclosure, retained derivative and counter-lifetime policy, deletion and rate-ledger cleanup, and has checked the actual deployment header boundary. No browser fingerprinting is used.

Keep ECHOWALL_SUBMISSIONS_ENABLED, ECHOWALL_REACTIONS_ENABLED and ECHOWALL_COUNTRY_CONTEXT_ENABLED off. Keep analytics off. Configure the independent reaction secret only after approval. Reactions have meaningful sorting when enabled and the schema is available. The read-only legacy wall is a bounded compatibility state and does not advertise complete counts or search. Public server logs must not record search queries or raw request bodies. The normal wall shows language only when reliable contribution metadata exists. The current migration does not infer a language from locale or country.

## Local review

Run the repository's existing EchoWall harness with its Community mode in a clean worktree. It provisions an unnamed-by-user disposable internal database, uses no external ports in Docker, and exposes a loopback-only browser proxy. Public submission, country and analytics stay OFF. Reactions are enabled only in the explicitly isolated synthetic runner. The local fixture route additionally requires loopback SITE_URL and host plus the exact local opt-in flag and rejects Vercel execution. Remove the local resources using the harness STOP file. No Production backup data, tokens, cookies or settings enter the gallery.

Country flag assets are the local 4:3 SVG set from [flag-icons 7.5.0](https://github.com/lipis/flag-icons/releases/tag/v7.5.0) under its MIT license. SVG elements are namespaced per code. The sprite issues no third-party requests and has a plain localized country-name alternative.
